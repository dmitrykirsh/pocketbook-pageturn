# PageTurn — листание страниц PocketBook с телефона по Wi-Fi

[English](README.md) · **Русский**

Позволяет листать страницы в **штатной читалке PocketBook** (pbreader) кнопками громкости Android-телефона — в том числе с погашенным экраном. Без Bluetooth, без замены прошивки и без KOReader.

| Часть | Что делает |
|---|---|
| **PageTurn (книга)** | Небольшой сервер на книге принимает UDP-команды `next` / `prev` и отправляет читалке нажатия аппаратных кнопок через официальный InkView SDK. Плюс экран приложения: IP, порт, PIN, QR-код. |
| **PageTurn Remote (Android)** | Перехватывает кнопки громкости (AccessibilityService) и шлёт команды на книгу. Находит книгу в сети, подключается по QR, переназначает клавиши. |

> ⚠️ **Что проверено.** Всё тестировалось **только** на одной книге **PocketBook 629 (Verse)** и одном телефоне **Xiaomi 14T Pro с HyperOS 3 (Android 16)**. Теоретически должно работать и на других PocketBook на Linux (InkView, ARMv7), но на них не проверялось. Используйте на свой страх и риск. Прошивка не изменяется: файлы кладутся на пользовательский раздел книги.

## Как это работает

```
Телефон (кнопка громкости) ──UDP "<PIN>:next"──▶ Wi-Fi ──▶ сервер на книге ──▶ нажатие кнопки ──▶ pbreader
```

- UDP, порт **57321**. Пакеты: `<PIN>:next`, `<PIN>:prev`, `<PIN>:ping`. Ответ на корректный пакет — `PTOK`.
- Защита — короткий PIN (4–8 цифр), задаётся на экране приложения на книге; неверные попытки ограничиваются по частоте.
- Автопоиск: телефон шлёт широковещательный `PTDISCOVER`, книга отвечает `PTHERE:<порт>:<имя>`. Работает и при раздаче Wi-Fi с телефона.
- QR на книге содержит `pageturn://c?h=<ip>&p=<порт>&k=<PIN>` — телефон подключается сразу со всеми настройками.
- Страницы листаются отправкой `IV_KEY_NEXT` / `IV_KEY_PREV` в активное приложение — как физическими кнопками.
- Сервер держит Wi-Fi включённым и запрещает книге засыпать. **Это увеличивает расход батареи** — останавливайте сервер (перезагрузка книги), когда не читаете.

## Установка

Скачайте файлы со страницы [Releases](../../releases/latest): `PageTurn-book-*.zip` и `PageTurnRemote-*.apk`.

### На книге

1. Подключите книгу к компьютеру по USB (режим доступа к накопителю).
2. Распакуйте `PageTurn-book-*.zip` **в корень диска книги** — появятся `applications/PageTurn.app` и `system/pageturn/…`.
3. *(Рекомендуется)* сделайте `system/pageturn` скрытой и системной, чтобы служебные файлы не показывались в библиотеке. Windows: `attrib +h +s system\pageturn`.
4. Отключите кабель. В меню приложений появится **PageTurn**.

Никакие библиотеки копировать не нужно: лаунчер использует системные библиотеки прошивки из `/ebrmain/lib`.

> Значок на рабочем столе (по желанию) нужно добавлять вручную в `system/config/desktop/view.json` с пересчётом `hash.txt`. Автор это делал, но в релиз не включает: ошибка может испортить рабочий стол. Запуск из меню «Приложения» работает без этого.

### На телефоне

1. Установите `PageTurnRemote-*.apk` (нужно разрешить установку из неизвестных источников; APK подписан отладочным ключом).
2. Откройте приложение и выдайте разрешения (камера — для QR, уведомления).
3. Включите **Специальные возможности → PageTurn Remote**. Без этого перехват кнопок громкости невозможен. На Xiaomi может понадобиться разрешить «ограниченные настройки» для приложения.
4. Подключитесь к книге: **«Сканировать QR»** на экране QR книги, либо **«Найти мою книгу»** и ввод PIN, либо вручную IP/порт/PIN.
5. Включите режим чтения. По умолчанию: громкость «вниз» — вперёд, «вверх» — назад (переназначается).

Телефон и книга должны быть в одной сети или книга — в точке доступа телефона.

## Использование на книге

1. Запустите **PageTurn** из меню приложений: стартует сервер в фоне и открывается экран.
2. Экран показывает адрес Wi-Fi, порт и **PIN**. Кнопки: *Сменить PIN*, *Случайный PIN*, *QR-код*, *Обновить*, *Закрыть*.
3. «Закрыть» закрывает только экран, **сервер продолжает работать**. Остановить — перезагрузить книгу.
4. Автозапуска при включении книги нет (корневая ФС прошивки только для чтения, её я не менял): после включения нужно один раз открыть приложение.
5. Первый запуск может идти дольше обычного — поднимается Wi-Fi.

Язык интерфейса — по языку системы книги: en, ru, uk, de, fr, es, it (иначе английский).

## Телефон с погашенным экраном

На протестированном Xiaomi (HyperOS 3) через ~10–15 секунд после выключения экрана система перестаёт передавать нажатия кнопок громкости сервисам. Как будет на вашем устройстве — неизвестно: возможно, всё заработает и без обходных путей.

Если у вас так же, на Xiaomi помог режим **«Тёмный экран»**: приложение держит экран включённым на минимальной яркости с чёрной картинкой (в том числе поверх блокировки). Чтобы экран «проснулся», подержите палец на нём (подсказка есть в приложении). Работает и когда телефон лежит экраном вниз.

Есть автоотключение по таймеру, чтобы кнопки громкости не оставались перехваченными навсегда, и плитка быстрых настроек.

## Сборка из исходников

```
android/   проект Android Studio / Gradle (Kotlin, Material 3, ZXing)
book/src/  исходники книжной части на C (server.c, ui.c, qr.c)
book/bin/  готовые бинарники для PocketBook 629
```

**Android** (JDK 17, Android SDK):

```bash
cd android && ./gradlew assembleDebug
```

**Книга** — кросс-компиляция в Docker:

1. Положите в `book/src/` заголовки из [pocketbook/SDK_6.3.0](https://github.com/pocketbook/SDK_6.3.0) (ветка 6.5, `inkview.h`). В репозиторий они не входят.
2. Положите `book/toolchain.tar.bz2` — тулчейн Bootlin armv7-eabihf glibc.
3. Скопируйте с книги библиотеки для линковки в `book/libs/` (`tools/collect-libs.app` кладёт их в папку `pageturn-libs` на книге; **файлы прошивки не публикуйте**).
4. `docker run --rm -v "$PWD/book:/work" debian:bookworm-slim bash /work/build.sh`
5. `book/patch.ps1 -Files out/pageturn,out/pageturn-ui`.

Нюанс: на книге soft-float EABI5, а тулчейн hard-float — после линковки патчится ELF (`e_flags = 0x05000200`, интерпретатор `ld-linux.so.3`). QR-кодер собственный (Reed–Solomon, версии 1–6, ECC M), проверен ZXing.

## Ограничения

- Только Wi-Fi и одна подсеть (широковещательный поиск не проходит через роутеры).
- PIN передаётся по UDP **без шифрования**. Защита — от случайного соседа по сети, не от целенаправленной атаки.
- Сервер не даёт книге заснуть — повышенный расход батареи.
- Нет автозапуска при загрузке книги.
- Проверено только на PocketBook 629 + Xiaomi 14T Pro / HyperOS 3.

## Удаление

Удалите с книги `applications/PageTurn.app` и `system/pageturn`, перезагрузите книгу. На телефоне отключите сервис в «Специальных возможностях» и удалите приложение.
